# MultiplierVerifier (Soroban Groth16 Verifier)

Generated by `astrolabe gen-verifier` in `Baked` mode for the `Multiplier2` circuit (`c <== a * b`, `n_public = 2`, `n_ic = 3`).

## Test Locally

```bash
cargo test -p multiplier-verifier
```

## Build WASM

```bash
stellar contract build --manifest-path examples/circom-multiplier/contract/Cargo.toml
```

The compiled WASM is written to `target/wasm32v1-none/release/multiplier_verifier.wasm`.

## Deploy to Stellar Testnet

```bash
stellar contract deploy \
  --wasm target/wasm32v1-none/release/multiplier_verifier.wasm \
  --source <IDENTITY> \
  --network testnet
```
